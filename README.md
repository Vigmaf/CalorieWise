# CaloriesWise
Python desktop application designed to estimate daily calories and macro requirements

## technologies
- python
- CustomTkinter
- SQLite
- unittest

## Features

- RMR calculation (Mifflin-St Jeor equation)
- Estimated daily calorie expenditure
- Weight loss, maintenance, and gain targets
- Personalized macronutrient recommendations
- Input validation
- SQLite calculation history 

## Install 

pip install -r requirement.txt

## Running

python main.py
